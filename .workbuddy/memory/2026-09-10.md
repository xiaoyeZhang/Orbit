# 2026-09-10

## 新增：特殊纪念日全站灰度（方案 A 落地）
- 需求：特殊节日/纪念日把 App 全站置灰。
- 调研结论（iOS 灰度三档）：A. SwiftUI 根视图 `.grayscale(1)`（官方、零风险）；B. UIKit window 层「灰色层 + `layer.compositingFilter = "saturationBlendMode"`」（可覆盖 UIKit 渲染）；C. 系统层 App 无法触及（键盘/系统弹窗/状态栏）。
- 关键坑：① `CALayer.filters` 在 iOS 是 no-op（仅 macOS 支持）；② UIAlertController/键盘/系统分享在独立 window，A/B 都盖不住；③ 别用 CIFilter 截图方案；④ `UIAccessibility.isGrayscaleEnabled` 可读系统灰度状态避免双重处理。
- **落地（OrbitApp.swift，未新建文件避开 pbxproj 注册）**：
  - 三个 `@AppStorage`：`orbit_grayscale`(最终生效值) / `orbit_grayscale_remote`(远端下发) / `orbit_grayscale_remote_set`(是否已下发)
  - RootView 链上 `.grayscale(grayscaleEnabled ? 1 : 0)` + `.animation(.easeInOut(0.5), value:)` + `.onAppear { refreshGrayscale() }`；scenePhase `.active` 时也刷新
  - 嵌套 `private enum GrayscalePolicy`：`fallbackDates: Set<String>`（MM-dd 格式，默认空=不用本地兜底），服务端下发优先
  - `refreshGrayscale()`：远端已下发→以远端为准；未下发→命中兜底日期则开启，未命中不主动关（便于 `-orbit_grayscale YES` 启动参数调试）
- **⚠️ 已知缺口**：SwiftUI `.sheet`/`fullScreenCover` 是独立呈现层，父视图的**图形效果修饰符不传递**（opacity/blur/grayscale 均不生效）→ 弹层内容不会被灰度。补齐两选项：① 逐处给 sheet 内容加 `@AppStorage("orbit_grayscale")` + `.grayscale(...)`（~15 处，纯官方 API）；② 改 window 层 saturation 混合层（一处覆盖全部，代价是半私有字符串 + 全屏合成开销）。
- 沙箱无法编译，需用户 Xcode Cmd+R 验证。
